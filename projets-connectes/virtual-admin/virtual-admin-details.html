3 Sécurité

La sécurité est organisée en 4 niveaux successifs, chaque niveau devant être franchi pour atteindre le suivant.

🔐 Niveau 1

Auth Streamlit
bcrypt + cookie

🔑 Niveau 2

Auth API
X-API-Key

🗄️ Niveau 3

Permissions PostgreSQL
writer / readonly

🔏 Niveau 4

Signature électronique
SHA-256 + HMAC

⚠️

SIGNATURE_SECRET ne doit jamais changer après émission de documents — sinon les PDF existants ne seront plus vérifiables.

5 Signature électronique

Chaque document PDF généré contient :

  1. Un hash SHA-256 du contenu (empreinte)
  2. Une signature HMAC de ce hash (preuve d'authenticité)
  3. Un QR code contenant une URL de vérification
📄 Document
→
SHA-256
→
🔑 SIGNATURE_SECRET
↓
HMAC-SHA256
→
📱 QR Code
→
📄 PDF + QR

Garanties

PropriétéMécanisme
IntégritéSHA-256 du contenu

Non-répudiationURL de vérification publique
Détection de falsificationRecalcul + comparaison
