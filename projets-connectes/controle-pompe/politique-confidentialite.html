📝 DESCRIPTION

Contrôle Pompe v5.0 est une application mobile Android permettant de piloter une pompe à distance via une carte ESP8266. Grâce à une connexion WiFi, vous pouvez contrôler les relais, programmer des horaires et gérer votre installation en mode LOCAL (connexion directe) ou DISTANCE (via routeur).

📡 COMMUNICATION

  • Connexion Wi-Fi directe (Point d'accès) ou via routeur
  • Aucune connexion Internet requise en mode LOCAL
  • Authentification par mot de passe
  • Compatible avec ESP8266 NodeMCU / ESP12F
  • Mémoire flash LittleFS pour la configuration

🔧 PRÉREQUIS MATÉRIELS

  • Carte ESP8266 NodeMCU ou ESP12F
  • Module relais (1 à 4 canaux selon besoin)
  • Alimentation 5V
  • Pompe à contrôler
  • Android 6.0 (API 23) ou supérieur
